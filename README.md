

# 💼 Portfólio / Currículo Web

Projeto desenvolvido como atividade prática de **HTML5**, com o objetivo de criar uma página de **Portfólio / Currículo Web** para um desenvolvedor.

A proposta é demonstrar conhecimentos em **estruturação semântica, tabelas, formulários, navegação interna e organização de conteúdo em HTML5**.

---

## 🎯 Objetivo

Criar uma página HTML limpa, semântica e funcional, reproduzindo a estrutura e a organização apresentadas no modelo da atividade.

O projeto apresenta informações pessoais, habilidades, projetos desenvolvidos e um formulário para contato.

---


### ✅ Cabeçalho e Navegação

- Título principal contendo nome e/ou cargo.
- Menu de navegação.
- Links internos para as seções:
  - Sobre Mim
  - Meus Projetos
  - Entre em Contato

### 👨‍💻 Sobre Mim

A seção apresenta:

- Foto de perfil com **150px × 150px**.
- Texto de apresentação.
- Lista com as principais habilidades do desenvolvedor.

### 🚀 Meus Projetos

Os projetos são apresentados em uma tabela contendo quatro colunas:

| Projeto | Tecnologias | Status | Link |
|---|---|---|---|
| Projeto 1 | Linguagem x | ex: Concluído | Acessar |
| Projeto 2 | Linguagem y | ex: Em andamento | Acessar |
| Projeto 3 | Linguagem Z | ex: Concluído | Acessar |


### 📩 Entre em Contato

O formulário de contato deve estar agrupado dentro de um `<fieldset>` com o título:

**Dados do Contato**

O formulário contém:

- Campo para **Nome**.
- Campo para **E-mail**.
- Menu suspenso `<select>` para **Assunto**.
- Área de texto `<textarea>` para **Mensagem**.
- Botão para envio.

Todos os campos possuem seus respectivos `<label>` vinculados corretamente.

### 📞 Rodapé

O `<footer>` apresenta:

- Direitos autorais utilizando o caractere especial `&copy;`.
- E-mail para contato.
- Telefone para contato.

---

## 🔧 Tecnologias Utilizadas

- HTML5
- Tags semânticas
- Links internos
- Tabelas HTML
- Formulários
- Fieldset e Legend
- Caracteres especiais HTML

> O projeto foi desenvolvido utilizando **HTML5 puro**, sem frameworks ou bibliotecas externas.
